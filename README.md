# naurydev · BETA

Descargas oficiales de naurydev para Windows 10 y 11 (64 bits).

## Instalar

1. Descarga **[naurydev-setup.exe](https://github.com/calum11112-source/naurydev-releases/releases/latest/download/naurydev-setup.exe)** (última versión).
2. Ábrelo y pulsa **Instalar**. Se instala solo para tu usuario, sin permisos de administrador, y crea el acceso directo en el escritorio.

Si Windows muestra «Windows protegió tu PC», pulsa **Más información → Ejecutar de todas formas**.

## Actualizaciones

naurydev comprueba sola si hay versión nueva al abrirse. Cuando la hay, la actualización es obligatoria: pulsas **Actualizar ahora**, se descarga, se instala y la app se vuelve a abrir sola.

## Desinstalar

Desde la app (**Uninstall**) o desde **Configuración → Aplicaciones → naurydev**.

Este es el único enlace oficial. Si alguien te pasa otro instalador, no lo abras y avisa en Discord.
